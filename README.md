# 📚 Quiz App

A simple and interactive **Quiz Application** built using **HTML, CSS, and JavaScript**.  
This project is perfect for beginners to learn DOM manipulation and basic JavaScript logic.

🔗 **Live Repository:**  
https://github.com/Faizahmad11/Quiz-app.git

---

## 🚀 Features

- ✅ Multiple choice questions  
- 🎯 Instant answer feedback (Correct / Incorrect)  
- 📊 Score calculation  
- 🔁 Restart quiz option  
- 🎨 Clean and simple UI  
- ⚡ No external libraries used  

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)

---

## 🎯 How It Works

* Questions are stored in a JavaScript array.
* Each question has multiple answers.
* When user selects an answer:

  * Correct answer turns **green**
  * Wrong answer turns **red**
* Score increases for correct answers.
* Final score is displayed at the end.
* User can restart the quiz.
